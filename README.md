# かんたんラベルメーカー

スマホで作る、かんたん商品ラベル・値札作成Webアプリ (PWA)

---

## 概要

スマートフォンだけで簡単な商品ラベル・値札・シールを作成し、画像（PNG）またはPDFとして保存・印刷できるWebアプリケーションです。

* **公開URL (GitHub Pages)**: https://sansyoudouwagasi.github.io/rabel/
* **オフライン・PWA対応**: 端末のホーム画面に追加してアプリ感覚で利用可能
* **完全ローカル保存**: サーバー送信なし、写真や商品データは端末内のIndexedDBに安全に保存

---

## 主な機能

1. **サイズ選択**:
   * 定番プリセット（30×20, 40×30, 50×30, 60×40, 80×50mm）
   * カスタムサイズ（幅・高さをmm単位で自由指定）
2. **テンプレート選択**:
   * シンプル（白、枠）
   * 和風（和紙風、紺×白、茶×ベージュ、上品な和風）
   * 商品（商品ラベル、値札）
   * 販促（SALE、おすすめ）
   * 白紙作成
3. **ラベル編集**:
   * 文字ツール（内容、フォントサイズ、太字、文字色、揃え、ゴシック/明朝体）
   * 画像ツール（スマホ撮影写真の長辺1200px自動圧縮、移動・拡大縮小・回転・削除）
   * 図形ツール（四角形、円、直線）
   * 背景色設定（パレット＋カラーピッカー）
   * 重なり順変更（前面へ・背面へ）
   * Undo / Redo（履歴30件）
   * 自動保存（1.5秒デバウンス）
4. **商品マスタ連携**:
   * 商品情報（商品名、価格、内容量、原材料、保存方法、消費期限、店名）の登録
   * エディタからワンタップでラベルへ自動配置
5. **保存・印刷・エクスポート**:
   * 高解像度PNG保存（300 DPI印刷基準）
   * 実寸単品PDF出力 & A4面付けPDF出力
   * A4用紙印刷プレビュー & ブラウザ実寸印刷
   * 全ラベルデータのJSONバックアップおよび復元
